# 🚀 PoojaConnect PRO – Online Pandit Booking Platform

PoojaConnect PRO is a full-stack web application developed using **Python, Django, MySQL, HTML, CSS, and JavaScript**.
The platform helps users easily find and book Pandits for various pooja services while enabling Pandits to efficiently manage appointments, payments, and communication.

---

# 📌 Features

## 👤 User Features

* User Registration & Login
* Search and Filter Pandits
* Book Appointments
* Real-Time Chat with Pandits
* Join Video Calls
* Online Payments using Razorpay
* Download Invoice PDF
* View Booking & Payment History
* Notifications System

---

## 🧘 Pandit Features

* Pandit Registration & Login
* Manage Profile & Expertise
* Accept / Reject Appointments
* Start Video Calls
* Generate Invoices
* View Payment History
* Chat with Users
* Notification System

# ⚙️ Installation Steps

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SarthakKumbhar18/PoojaConnect_PRO.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd PoojaConnect_PRO
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux/Mac

```bash
source venv/bin/activate
```

---

## 5️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

## 6️⃣ Configure Database

Update database settings in `settings.py`

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'PoojaConnectPro_DB',
        'USER': 'root',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': '3306',
    }
}
```

---

## 7️⃣ Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

---

## 8️⃣ Create Superuser

```bash
python manage.py createsuperuser
```

---

## 9️⃣ Run Server

```bash
python manage.py runserver
```
